Лабораторна робота №6.  Реалізація методів роботи з базами даних з використанням SQL та HQL.
 
Мета роботи: навчитись реалізовувати методи роботи з БД на основі Native SQL та HibernateQL (HQL).

Завдання:
1. Опрацювати теоретичний матеріал за темою 
2. Створити структуру maven-проекту.
3. Підключити необхідні бібліотеки (Hibernate Сore,
Hibernate Entity Manager, Validation). Здійснити налаштування файлу properties.xml.
5. Розробити entity та dao (здійснити абстрактний опис методів роботи з ДБ) для обраної теми дослідження.
6. Зенерувати стуруктуру БД з використанням технології  Hibernate
7. Реалізувати абстрактні методи dao з використанням Native SQL.
8. Створення реалізації абстрактних методів dao з використанням HibernateQL (HQL).
9. Провести тестування запитів до бази даних (JUnit).
10. Оформити звіт про виконану роботу.
11. Зробити висновки щодо виконаної роботи.
